# Site de Aniversário — preto & rosa ❤️

## Como usar
1. Abra `index.html` no navegador para testar.
2. Troque `[NOME]` pelo nome da aniversariante.
3. Troque `[SEU NOME]` pelo seu nome.
4. Se quiser música, coloque um arquivo chamado `musica.mp3` dentro de `assets/`.
5. Para publicar na Vercel, envie a pasta inteira como projeto estático.

As fotos já estão dentro de `assets/`.
